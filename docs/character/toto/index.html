🐶 토토 (Toto the Puppy)

"멍멍! 도로시, 여기 부탁한 220옴 저항이랑 브레드보드 가져왔어! 실패해도 괜찮아, 다시 해보자 왈!"

도로시의 곁을 든든하게 지키는 순백색 믹스견 강아지! 저항과 점퍼선을 입에 물어다 주고, 복잡한 회로 연결에 지쳤을 때 꼬리를 흔들며 따뜻한 온기와 사기를 불어넣어 주는 비타민 같은 친구입니다.

▲ 공식 마스터 프로필 컷

--- ## 📐 1. 해부학적 형태 및 신체 비례 규격 (Anatomy & Proportions) | 부위 | 규격 및 조형 세부 원칙 | | :--- | :--- | | **품종 및 체형** | **귀엽고 통통한 믹스견/말티푸 모티브 2.5등신 주니어 강아지**
• 복슬복슬하고 부드러운 웜 밀크 화이트/크림 단색 모질 (얼룩점 일체 배제)
• 짧고 탄탄한 네 다리와 기분 좋게 말려 올라간 복슬복슬한 꼬리 | | **얼굴 & 코** | • 코: 윤기 흐르는 까만 단추 코 (Black Button Nose, `#1E1E1E`)
• 눈: 반짝이는 동그란 까만 단추 눈과 눈꼬리의 맑은 반사광
• 입: 혀를 살짝 내밀고 활짝 웃는 해맑은 팬팅(Panting) 미소선 | | **귀 (Ears)** | • 볼 옆으로 자연스럽게 늘어진 부드러운 플로피 이어 (Floppy Ears)

• 물고 다니는 소품: 알록달록한 점퍼 와이어, 220옴 저항 밴드, 부품 상자 | --- ## 🎨 2. 화풍 및 렌더링 물리 규격 (Rendering Physics) 1. **선화 (Line Art Mechanics):** - 선 색상: 다크 에스프레소 브라운 (`#26211E`) - 털 외곽선: 날카로운 가시털이 아닌, 뭉게구름처럼 둥글둥글하고 포근한 2D 곡선 2. **채색 및 셰이딩:** - 털 기본색: 차가운 흰색이 아닌 **포근한 웜 밀크 크림 화이트 (`#FBF6EB`)** - 그림자: 살구빛이 은은하게 감도는 부드러운 웜 베이지 셰이드 (`#F0E5D3`) --- ## 🌈 3. 표준 컬러 팔레트 (Color Hex Codes) | 영역 | 세부 항목 | 색상 명칭 | Hex Code | 컬러 프리뷰 | | :--- | :--- | :--- | :--- | :---: | | **신체** | 털 밑색 | Warm Milk White | `#FBF6EB` | | | | 털 그림자 | Soft Warm Beige | `#F0E5D3` | | | | 단추 눈/코 | Jet Black Button | `#1E1E1E` | | | | 혀 (Tongue) | Cheerful Rose Pink | `#F28D9E` | | | **소품** | 시그니처 반다나 | Sky Blue Bandana | `#2D9CDB` | | --- ## 🖼️ 4. 공식 학습 데이터셋 갤러리 (Dataset & Variations) `data/dataset/toto/` 디렉토리에 구축된 고해상도 학습 데이터셋의 대표 컷입니다.
